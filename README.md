# ЛР по ЧМ на ФИИТе в МАИ
Лабораторные работы по дисциплине "Численные методы" в пятом семестре 2026/2027 учебного года направления "Фундаментальная информатика и информационные технологии" в [Московском авиационном институте](https://mai.ru)

## Требования
1. Все лабораторные работы сдаются в виде программного кода. Использовать можно любой язык программирования.
2. Входные данные не должны вводиться через консоль или быть захардкожены в коде. Можно сделать небольшое приложение с формой для ввода данных или реализовать чтение данных из файла.
3. Программа должна быть универсальной. Размерность матрицы не должна быть жёстко задана в коде: при вводе матрицы большей размерности программа должна продолжать корректно работать, если входные данные соответствуют условиям применимости метода.
4. Использовать готовые реализации численных методов нельзя. Например, **NumPy** можно применять только для проверки и сравнения результатов собственной реализации, если в требованиях к конкретному заданию не указано иное.
